# Everyday Words (learn-english)

Mobile-first vocabulary PWA. Design: `docs/plans/2026-11-23-vocab-pwa-design.md`.

## Commands

- `npm run dev` — dev server
- `npm test` — Vitest (SRS, quiz, session logic, topic data validation)
- `npm run typecheck` / `npm run build`
- `npm run images [-- <topicId>...] [--force]` — fetch Wikimedia images for words into `public/images/` (needs `cwebp`)

Install deps with `npm install --before=<date 7+ days ago>`. The local npm registry is a corporate Artifactory mirror;
keep `package-lock.json` `resolved` URLs on `https://registry.npmjs.org/` (CI uses `npm install`).

## Data

- `data/topics/<id>.json`: one topic per file. Word id = `<topicId>.<slug(en)>`. US English in `en`, British variant in `uk`.
- Image source per word: `img` (Commons file name) > `wiki` (English Wikipedia article title, uses its page image) > `en`. `noimg: true` = no image.
- `data/images.json` is generated by the image script; don't edit by hand.
- Review downloaded images visually; Wikipedia page images are often wrong (diagrams, wrong sense).

## Notes

- Progress is stored in `localStorage` (IndexedDB via idb-keyval hung in headless Chrome).
- HashRouter + `base: './'` so it works on any GitHub Pages path.
- Headless Chrome screenshots: use `--timeout`, not `--virtual-time-budget`; window width ≥ 500.
